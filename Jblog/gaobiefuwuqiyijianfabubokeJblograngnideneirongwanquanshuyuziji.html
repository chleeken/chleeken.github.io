#告别服务器，一键发布博客——Jblog让你的内容完全属于自己

2026年09月13日|作者:靳好宝|栏目:Jblog|分类:博客建站 # 告别服务器，一键发布博客——Jblog 让你的内容完全属于自己 　　做个人博客，你是不是也经历过这样的折腾： 　　注册一个平台，花心思排版，结果发现文章数据全锁在云端，想导出？格式丢失，链接断裂。换个平台？重新来过。样式想改一点？平台规则卡得死死的。更别提那些「功能更新」「账号策略调整」，你的内容命脉，永远握在别人手里。 　　后来我想换个思路：**能不能让写博客这件事，回到最朴素的形态——我写，我存，我发，我的东西归我管？** 　　Jblog 就是基于这个想法做出来的。 　　## 它到底是个什么东西 　　Jblog 是一个**本地桌面博客发布工具**，基于 Python + Tkinter，不需要服务器、不需要数据库、不需要注册任何账号。 　　整个流程一句话就能说清： 　　> **在编辑区写完正文 → 点「发布」 → 生成标准静态 HTML → 丢进任意静态空间 → 你的博客就上线了。** 　　没有云端，没有 API 调用，没有平台依赖。产物就是一堆 `.html` 文件，往 GitHub Pages、Cloudflare Pages、甚至网盘静态托管里一放，打开就能访问。 　　## 解决什么痛点 　　很多人觉得「写博客」这件事的门槛在**写作**，其实真正的门槛在**发布和维护**环节： 　　- 写完之后要手动导出、手动上传、手动维护链接 　　- 首页要手动更新，sitemap 要手动生成 　　- 图片要手动压缩、手动改文件名 　　- 想换平台，全部推倒重来 　　Jblog 把这条链路全部自动化了： 　　**写作端：** 　　- 纯文本所见即所得编辑，不跟富文本编辑器较劲 　　- 快捷键插入常用标签，一键插入当前时间 　　- 本地图片自动转 WebP，宽度超 600px 自动等比缩放，中文文件名自动转拼音 　　- 网络图片 URL 粘贴后自动下载转换，补齐 `alt`、`width`、`height` 属性 　　**格式化端：** 　　- 删多余空行、行首空格、行内空格 　　- 「规范」功能：自动按行首空格识别段落，包裹 `

` 标签，文末生成关键词摘要 　　- 基于 jieba 分词提取高频关键词，随机插入关键词、已有链接、尾随链接 　　**发布端：** 　　- 基于模板生成单篇 HTML，自动填充标题、日期、作者、栏目、描述、关键词 　　- 文末自动插入最近链接 　　- **同步维护 `url.txt`、栏目索引、sitemap——你只管写，它管剩下的** 　　- 首页自动生成分页（每 30 条一页），过期分页自动清理 　　## 为什么说它「省心」 　　最打动我的是它的**配置文件自管理**机制： 　　启动时自动检查并创建 `domain.txt`、`栏目.txt`、`作者.txt`、`分类.txt`、`关键词.txt` 等，缺省带默认值。第一次打开就知道该填什么，没有空白的配置文件等着你手动创建。 　　目录结构也设计得很清晰：每个栏目对应一个子目录，文章、图片、`url.txt`、sitemap 全在一起。还有一个 `栏目-txt` 目录存带全局序号的 TXT 原文备份——**你永远有一份纯文本底稿，随时可迁移、可备份、可读。** 　　多编码兼容做得也很细：自动检测 BOM，无 BOM 时先走 chardet，再依次尝试 utf-8、gbk、gb2312、gb18030、big5、utf-16、ascii。你从老系统、不同编辑器里拖出来的 TXT，基本都能读进去。 　　## 适合谁用 　　- **习惯纯文本写作的人**——不想被 Markdown 的语法标记分心，也不想被富文本编辑器的按钮海洋淹没 　　- **重视内容自主权的人**——所有数据本地留存，随时可导出，不跟任何平台绑定 　　- **已有静态托管空间的人**——只缺一套「写完即出网页」的工具，Jblog 就是那个工具 　　- **个人站维护量大的人**——sitemap、首页索引、链接维护全自动化，省掉大量重复劳动 　　## 技术栈 　　Python 3.10+、Tkinter（标准库）、jieba、pypinyin、Pillow、chardet。打包支持 PyInstaller 和 Nuitka，编译后是一个独立可执行的 `.exe`，双击就能用，不需要装 Python 环境。 　　## 写在最后 　　Jblog 的价值不在花哨，而在于把「写」和「发」这条链路做成了闭环。 　　对希望内容自主可控的人来说，它把发布环节压成了**一次点击**。 　　你的博客，你的数据，你的规则。 　　--- 　　*Jblog 是一款开源的本地博客发布工具，欢迎体验。后续版本将增加草稿与批量发布、模板在线预览、CI 自动部署对接等能力，让静态站维护更省心。*

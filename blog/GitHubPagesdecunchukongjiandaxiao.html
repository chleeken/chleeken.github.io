GitHubPages的存储空间大小

2026年10月11日|作者:靳好宝|栏目:blog|分类:互联网络

  GitHub Pages的存储空间大小

  GitHub Pages 的存储空间有明确的大小限制，主要分为源仓库和发布后的站点两个方面。

  核心存储限制

  根据 GitHub 官方文档，限制如下：

  源仓库建议限制：用于存放 GitHub Pages 源文件的仓库，其建议大小上限为 1 GB。这并非硬性上限，但超出后可能会收到警告或建议优化。

  已发布站点大小：通过 GitHub Pages 发布后的网站，其总大小不得超过 1 GB。这是必须遵守的硬性限制。限制

  其他相关使用限制

  除了存储空间，GitHub Pages 还对其他资源使用有所限制，这些限制可能会间接影响你的站点规模：

  带宽限制：站点有每月 100 GB 的软带宽限制。超出后，GitHub 可能会联系你建议优化或迁移。

  构建频率：站点有每小时最多 10 次构建的软限制。如果使用自定义 GitHub Actions 工作流，则不受此限制。

  部署超时：每次部署如果超过 10 分钟，将会超时失败。建议，

  注意事项

  限制性质：“建议限制”通常表现为警告，而“不得超过”的限制则是硬性的，可能导致部署失败或站点被暂停服务。

  超额后果：如果站点超出使用配额，GitHub 可能会暂停服务，或通过邮件建议你将内容分发网络 (CDN) 置于站点前、使用 Releases 功能，或迁移到其他托管服务。GitHub，

  总结来说，规划 GitHub Pages 项目时，请确保源仓库和最终发布的站点都控制在 1 GB 以内，并留意每月的带宽消耗。

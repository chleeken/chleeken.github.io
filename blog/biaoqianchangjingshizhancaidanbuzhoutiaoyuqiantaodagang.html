              ## 二、步骤条（Step Indicator / Wizard）

              步骤条本质是**有序列表**——"第一步、第二步……"是有先后顺序的，语义上必须用 `

              `，不能用 `
                `。

                  ### 2.1 最小可用结构

                  ```html

                  

                    

                1.   1

                    填写信息

                    

                  2.   

                2.   2

                    支付

                    

                  3.   

                3.   3

                  ### 2.2 水平步骤条（带连接线，生产级）

                  CSS：用 `::before` 画连接横线，用 `:last-child` 隐藏尾线。

                  display: flex;

                  .step

                  position: relative;

                  flex: 1;

                  text-align: center;

                  counter-increment: step;

                  

                  /* 连接横线 */

                  .step:not(:first-child)::before

                  content: '';

                  position: absolute;

                  top: 50%;

                  left: calc(-50% + 1rem);

                  right: calc(50% + 1rem);

                  height: 2px;

                  background: #e0e0e0;

                  

                  .step.done::before,

                  .step.none，active::before

                  height: 2.5rem;

                  border-radius: 50%;

                  background: #e0e0e0;

                  color: #666;

                  font-weight: 600;

                  

                  .step.done .step-num

                  background: var(--accent, #4f46e5);

                  ### 2.5 常见坑

                  | 坑 | 后果 | 正确做法 |

                  |---|---|---|

                  | 用 `

                  ` 写步骤 | 丢失"有序"语义，读屏器不报"第 N 步" | 必须 `
                    ` |

                      | 连接横线用 `

                      | `flex: 1` 但圆点没 `margin: auto` | 圆点偏左 | `text-align:center` + `inline-flex` |

                        ## 三、嵌套大纲（Nested Outline / 树形目录）

                        典型场景：文档目录（TOC）、思维导图节点、配置项树。

                        ### 3.1 最小可用结构

                        ```html

                        

                          

                      •   第一章 引言

                          

                            

                        •   1.1 背景

                            

                              

                          •   1.1.1 问题陈述

                              

                              

                            •   

                            

                          •   

                        • 1.2 目标

                          •   

                          

                        •   

                      • 第二章 方法

                        •   

                        ```

                        ### 3.2 可折叠树（生产级）

                        HTML：每层 `

                    1. ` 带 `class="toggle"` 和 `aria-expanded`，`

                        引言

                        

                          

                      •   

                          1.1 背景

                          

                            

                        • 1.1.1 问题

                          •   

                        • 1.1.2 现状

                          •   

                          

                        •   

                        

                      2.   

                  ```

                  > `role="tree"` 系列 ARIA 较重，简单场景可省略 `role` 只留 `aria-expanded`。

                  CSS：

                  ```css

                  .outline list-style: none; padding-left: 0;

                  .outline ul list-style: none; padding-left: 1.5rem;

                  .outline li

                  display: flex;

                  align-items: center;

                  gap: .375rem;

                  padding: .25rem 0;

                  

                  .toggle

                  width: 1.25rem;

                  height: 1.25rem;

                  border: none;

                  background: transparent;

                  cursor: pointer;

                  font-size: .8rem;

                  

                  li[aria-expanded="false"] > .toggle transform: rotate(0deg);

                  li[aria-expanded="true"] > .toggle transform: rotate(90deg);

                  ```

                  JS（折叠/展开，事件委托）：

                  ```js

                  document.querySelector('.outline').addEventListener('click', e =>

                  const btn = e.target.closest('.toggle');

                  if (!btn) return;

                  const li = btn.closest('li');

                  const sub = li.querySelector(':scope > ul');

                  const open = li.getAttribute('aria-expanded') === 'true';

                  li.setAttribute('aria-expanded', String(!open));

                  btn.setAttribute('aria-expanded', String(!open));

                  sub?.toggleAttribute('hidden');

                  );

                  ```

                  ### 3.3 纯 CSS 折叠（零 JS 版，适合内容少）

                  ```html

                  

              •   

                  

                  

                  …

                  

                •   ```

                  ```css

                  .chk display: none;

                  .chk:not(:checked) ~ ul display: none;

                  ```

                  > 零 JS 方案优点：无状态管理；缺点：`` 状态不持久化、深层嵌套选择器难写。

                  ### 3.4 动态生成（JS 渲染嵌套树）

                  ```js

                  function renderOutline(nodes, parentEl)

                  const ul = document.createElement('ul');

                  ul.classList.add('outline');

                  for (const node of nodes)

                  const li = document.createElement('li');

                  li.textContent = node.title;

                  if (node.children?.length)

                  renderOutline(node.children, li);

                  li.setAttribute('aria-expanded', 'true');

                  

                  ul.appendChild(li);

                  

                  parentEl.appendChild(ul);

                  

                  ```

                  ### 3.5 常见坑

                  | 坑 | 后果 | 正确做法 |

                  |---|---|---|

                  | 嵌套用 `

                ` | 读屏器不报层级 | 每层 `
                • ` |

                    | `padding-left` 每层固定 1.5rem | 深层右移过多 | 用 `indent` 或每层递增 `calc(var(--depth) * 1rem)` |

                    | `hidden` 属性没加在 `

                    ` 上 | 折叠后仍占空间 | `sub.hidden = true` |

                      | 纯 CSS 方案 `

                      | 动态渲染没 `role` | 键盘导航缺 | 按 WCAG 给 `tree/treeitem` role |

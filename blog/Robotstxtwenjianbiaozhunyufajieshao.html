  Allow: 允许访问的路径。用于覆盖 Disallow。非标准但广泛支持。Google 支持。

  Sitemap: 绝对 URL，指向 sitemap。非组内指令，不受 User-agent 影响。可多个。

  组规则：

  Robots.txt 文件语法介绍 robots.txt 是放在网站根目录下的纯文本文件，用于告诉搜索引擎爬虫哪些 URL 可以抓取、哪些不可以。标准地址必须是：

  text https://chleeken.github.io/robots.txt 子目录中的 robots.txt 无效，例如 /blog/robots.txt 不会被识别。每个子域名也需要单独设置。

  基本语法 每行一条指令，格式为：

  text 字段: 值

表示注释，可整行或写在行尾。

  字段名通常不区分大小写，但路径值区分大小写。

  空行可分隔记录，但通常以下一个 User-agent 开始新组。

  建议使用 UTF-8 编码。

  文件需可公开访问，返回 HTTP 200。

  常用指令 指令 作用 示例 User-agent 指定规则适用的爬虫 User-agent: * Disallow 禁止抓取的路径 Disallow: /admin/ Allow 允许抓取的路径，用于覆盖 Disallow Allow: /admin/public/ Sitemap 指定 Sitemap 地址，必须是绝对 URL Sitemap: https://chleeken.github.io/sitemap.xml Crawl-delay 请求间隔秒数，非标准，Google 不支持 Crawl-delay: 10 Host 指定主域名，非标准，Yandex 支持 Host: example.com User-agent: * 表示所有未单独指定的爬虫。可以为一个爬虫或多个爬虫设置同一组规则：

  text User-agent: Googlebot User-agent: Bingbot Disallow: /private/ 如果爬虫匹配了特定组，通常会忽略 * 组。例如：

  text User-agent: * Disallow: /

  User-agent: Googlebot Allow: / 这表示除 Googlebot 外，其他爬虫禁止抓取全站；Googlebot 允许抓取全站。

  路径匹配规则 路径以 / 开头，相对于网站根目录。

  不加通配符时，按前缀匹配。 Disallow: /private 会匹配 /private、/private/、/private.html、/private123。

  • 匹配任意字符序列。 Disallow: /*.pdf$ 禁止所有以 .pdf 结尾的 URL。

  $ 匹配 URL 结尾。 Disallow: /index.html$ 只禁止 /index.html，不禁止 /index.html?page=2。

  冲突时，通常最长匹配优先；如果 Allow 和 Disallow 长度相同，广泛实现中 Allow 优先。

  规则也常匹配查询字符串，例如 Disallow: /? 可禁止带查询参数的 URL。

  示例 text

所有爬虫

  User-agent: * Disallow: /admin/ Disallow: /tmp/ Allow: /admin/public/ Disallow: /.pdf$ Disallow: /?*

单独控制 Googlebot

  User-agent: Googlebot Disallow: /no-google/

  Sitemap: https://chleeken.github.io/sitemap.xml 其中：

  /admin/ 禁止抓取，但 /admin/public/ 允许。

  所有 .pdf 结尾文件禁止抓取。

  带查询参数的 URL 禁止抓取。

  Googlebot 额外禁止 /no-google/。

  Sitemap 不属于某个 User-agent 组，可放在任意位置。

  注意事项与常见误区 robots.txt 不是安全机制 它只是爬虫协议，恶意爬虫、采集程序可以完全忽略。敏感内容应使用登录、权限控制。

  Disallow 不保证页面不被索引 如果其他网站链接了该 URL，它仍可能出现在搜索结果中，只是没有摘要。要阻止索引，应使用 noindex，但 noindex 需要页面能被抓取。

  不要阻止 CSS、JS 搜索引擎需要抓取 CSS/JS 来渲染页面。阻止它们可能影响收录和排名。

  文件位置必须正确 只能是域名根目录下的 /robots.txt，子目录无效。

  状态码有影响 返回 404 通常被视为“允许抓取全部”；返回 5xx 时，部分爬虫会暂停抓取。

  更新不一定立即生效 爬虫会缓存 robots.txt，修改后可能需要一段时间才生效。

  大小限制 Google 等爬虫通常只处理前 500 KiB 内容，建议保持文件简洁。

  简单说：robots.txt 用于爬虫抓取管理，核心是 User-agent、Disallow、Allow、Sitemap，配合 * 和 $ 做路径匹配，但不能当作安全或强制索引控制手段。
